# Fetches

A quiet daily journal. Choose a mood, write one note, keep a streak — everything stays in your browser (`localStorage`).

## Live site

**https://calap0309.github.io/lumen-journal/**

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Stack

- React + TypeScript
- Vite
- GitHub Pages
